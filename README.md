# Employee Insights Dashboard – Power BI
## Project Overview
The Employee Insights Dashboard is an interactive Power BI project designed to analyze employee information and provide insights into workforce demographics, salary distribution, hiring trends, and employee performance indicators.
The dashboard helps users understand employee distribution and monitor important workforce KPIs.
## Dashboard Preview
![Employee Insights Dashboard](Screenshots/Employee_Insights_Dashboard.png)
## Key Features
- Employment Type Analysis – Full-time, Part-time, and Contract employees.
- Age Group Analysis – Employee distribution by age.
- Pay Type Analysis – Hourly and Salary-based employees.
- Gender Analysis – Gender distribution across the workforce.
- Ethnic Group Analysis – Workforce diversity insights.
- Employee KPIs – Total Hired Employees, Average Salary, and Employee Count.
- Hiring Trends – Employee hiring growth over time.
- Employee Indicators – Average Salary, Average Tenure, and Leave Balances.
- Sick Day Analysis – Sick leave balance evaluation.
- Salary Cost Analysis – Estimated total salary costs.
## Tools and Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Data Visualization
- KPI Reporting
## Dashboard Development Process
1. Imported employee data into Power BI.
2. Performed data cleaning and transformation using Power Query.
3. Created relationships and developed the data model.
4. Created measures and calculated columns using DAX.
5. Designed interactive charts, KPI cards, and tables.
6. Developed the final dashboard for employee analytics.
## Business Benefits
- Provides a clear view of workforce distribution.
- Helps analyze employee hiring trends.
- Supports salary and leave balance monitoring.
- Makes employee information easier to understand through visual reporting.
